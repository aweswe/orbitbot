# Deferred from the single-authority pass

These are intentionally out of scope until the web alpha holds and billing is green.

- Desktop signing/notarization, Electron fuses/ASAR integrity, auto-update feed.
- Mobile rebrand and EAS ownership: `com.rakazo.app`, `rakazo://`, Expo owner `inbox-zero`, extension IDs, app group.
- Voice, image, video, and third-party memory metering. In cloud mode these surfaces are disabled rather than metered.
- Orbit Chat UI parity port: sequence is canonical identity → one credit meter → Forion catalog → shared settings/tokens → components → `ui-parity` visual diff.
- Regional/autoscaling work, cost model, and provider catalog governance.
- Orbit Chat packaging (Nodebox/GSAP) until the “is Orbit Chat shipping” decision is made.
