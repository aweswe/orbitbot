# Orbit Bot

> 由 Forion 提供支持的 Orbit 产品。

Orbit Bot 是构建在 Forion 平台上的 Orbit 产品。它为 AI 智能体提供持久化的 Linux 计算机、浏览器、Shell、文件和桌面，并支持多个智能体在同一工作区中协作。可在 Web、桌面 (Electron) 和移动端 (Expo) 使用。

## 主要功能

- **持久化计算机** — 每个机器人会在任务之间保留文件、浏览器和工作区。
- **真实工具** — 读写文件、运行命令、浏览网页，并连接 MCP 工具。
- **多智能体协作** — 群聊、任务交接和子智能体分工。
- **例程与触发器** — 定时任务和 Webhook 无需等待提示即可开始工作。
- **审批** — 在重要操作前暂停，可单次批准、始终批准或接管。
- **随处使用** — 在 Web、桌面和移动端访问同一工作区。
