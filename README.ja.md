# Orbit Bot

> Forion が提供する Orbit 製品。

Orbit Bot は、Forion のプラットフォーム上に構築された Orbit 製品です。AI エージェントに永続的な Linux コンピューター、ブラウザ、シェル、ファイル、デスクトップを提供し、複数のエージェントが同じワークスペースで協力できるようにします。Web、デスクトップ (Electron)、モバイル (Expo) で利用できます。

## 主な機能

- **永続コンピューター** — 各ボットはタスク間でファイル、ブラウザ、ワークスペースを保持します。
- **実際のツール** — ファイルの読み書き、コマンド実行、Web 閲覧、MCP ツールへの接続。
- **マルチエージェント** — グループチャット、ハンドオフ、サブエージェントによる作業分担。
- **ルーティンとトリガー** — スケジュールタスクと Webhook で、プロンプトを待たずに作業を開始。
- **承認** — 重要な操作の前に一時停止し、一度だけ許可、常に許可、または引き継ぎを選択。
- **どこからでも利用** — Web、デスクトップ、モバイルで同じワークスペースにアクセス。
